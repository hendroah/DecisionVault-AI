DecisionVault AI 🧠⛓️
On-chain intelligence for decentralized teams.
DecisionVault AI is a production-grade, AI-native SaaS platform designed for the 0G (Zero Gravity) ecosystem. It allows DAOs, Web3 protocols, and modern leadership teams to store, verify, and execute strategic decisions using Verifiable AI and Decentralized Storage.
🚀 Features
Verifiable AI Inference: Generate pros, cons, and confidence scores using AI running on decentralized compute nodes.
Immutable Storage: Pin strategic proposals and signatures directly to the 0G Storage Network.
Zero-Knowledge Proofs: Automatically generate ZK-Proofs for every AI synthesis to guarantee output integrity.
On-chain Timeline: A fully searchable, cryptographic ledger of your organization's history.
Team Multi-sig: Interactive team workspaces with required cryptographic approvals.
🛠 Tech Stack
Framework: React + Vite
Styling: Tailwind CSS
Animations: Framer Motion
Icons: Lucide React
Language: TypeScript
AI Model: Gemini API (Verifiable AI Simulation)
📦 Quick Start
1 Install dependencies
npm install
2 Run the development server
npm run dev
Open http://localhost:5173 with your browser to see the application.
3 Build for Production
npm run build
 Deploying to Vercel
This repository is pre-configured for seamless deployment to Vercel.
Create a new GitHub repository and push these files to it.
Go to Vercel and click Add New Project.
Import your newly created GitHub repository.
Vercel will automatically detect the Vite framework.
Click Deploy. Your app will be live in seconds!
